# Checkpoints de validação

Use estes checkpoints para comparar o recomp com o emulador. Para cada um, guarde: frame, screenshot, estado do input e, se possível, um hash da WRAM.

| ID | Cena | Como chegar | Estado |
|---|---|---|---|
| CP-000 | Boot / logo Atlus | iniciar o jogo | pendente |
| CP-001 | Tela de título | aguardar o boot | pendente |
| CP-002 | Seleção de save | apertar Start no título | pendente |
| CP-003 | Introdução / novo jogo | escolher um slot vazio | pendente |
| CP-004 | Primeira sala da dungeon | terminar a introdução e andar | pendente |
| CP-005 | Primeira batalha | andar até um encontro | pendente |
| CP-006 | Menu de status | abrir o menu | pendente |
| CP-007 | Salvar e carregar | salvar, reiniciar, carregar | pendente |
| CP-008 | Início do Megami Tensei II | completar o MT1 ou usar save de teste | pendente |

## Formato sugerido de registro

```text
ID:
Data:
Build/commit:
ROM (CRC32):
Frame:
Input:
Screenshot:
WRAM hash:
Resultado:
Observações:
```
